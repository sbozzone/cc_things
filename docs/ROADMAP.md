# ToDone recommendation roadmap

The product should stay calm and action-oriented. New capability belongs behind existing
workflows until the user chooses it; no recommendation or automation silently changes a
task.

## Phase 1 — review and daily planning

- [x] Guided Weekly Review under More lists
- [x] Optional My Day suggestions for important and soon-due available work

## Phase 2 — dependable reminders

- [ ] Web Push subscriptions per signed-in device
- [ ] Server-side delivery with idempotent reminder generations
- [ ] Notification permission and device-management controls

## Phase 3 — realistic daily capacity

- [ ] Optional task effort estimates
- [ ] My Day estimated-load total and lightweight capacity warning
- [ ] Time-blocking only after estimates prove useful in normal list planning

## Phase 4 — supporting material

- [ ] Photo and file attachments with explicit storage limits
- [ ] Private object storage, signed access, export, and account-deletion coverage

## Phase 5 — reusable views

- [ ] Save the current search and filters as an optional named view
- [ ] Keep saved views under More lists unless explicitly pinned
